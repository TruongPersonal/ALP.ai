# ALP.ai
ALP.ai là **trợ lý số hỗ trợ học tập** cho **người khiếm thị** theo tiêu chuẩn **WCAG 2.2**.

---

## ⚙️ Cách hoạt động
- **Extractor** trích xuất toàn văn bản thô từ tài liệu. 
- **AI Pipeline** sinh đề thi ngẫu nhiên, tóm tắt từ tài liệu.
- **AI Grading** tiếp nhận, chấm điểm và đưa ra nhận xét.
- **WCAG 2.2 AA** tuân thủ tiêu chuẩn tiếp cận quốc tế.

---

## 🚀 Cách sử dụng
1. Nhập mã token thử nghiệm `ALP123` để đăng nhập nhanh với tài khoản sinh viên mẫu.
2. Nhấn **Tải tài liệu** để tải lên giáo trình PDF/DOCX môn học mới.
3. Nhấn **Đọc bài** để xem tóm tắt môn học đã được biên soạn.
4. Nhấn **Thi thử** để làm đề thi và nhấn **Nộp bài** để xem kết quả.

---
